### 设置、首页和模型输出

- 模型地址、模型名称、API Key 和分组偏好缺失、空值或纯空白时保留已有值。首次配置仍要求地址和模型，只有明确清除才删除 Key；更换服务地址时不得自动复用旧 Key。
- 首页默认近 3 天有更新的主会话加全部网页，按最近活动筛选，与创建时间排序独立。每次更新重建可见分组和类型选项；空项目自动清理，归档或范围外记录保留归属，撤销可恢复原组。
- 会话已有原名、人工别名或固定名称时跳过补名。首条消息排除已知的顶层系统说明和恢复包装；无法可靠找到首条消息时保持缺失，不使用中段消息替代。
- 模型使用短项目编号，允许唯一且完全相等的项目名称；不接受模糊匹配或猜测。无效引用最多纠正一次，复用授权输入和总超时，错误模型文本不进入重试上下文。
- 模型测试使用两条虚构网页的完整分类，复用正式解析器；仅返回 `ok:true`、漏掉记录或仅给标签均不能通过。测试不发送真实记录或个人偏好。
- 整理错误显示简短原因和处理建议，原始错误折叠并转义。后台每批应用的结果独立保留；后续批次失败不撤回先前已完成的修改。
- “历史网页”指未关联当前页签的旧浏览器记录，与项目分类独立。已有分类保留，可重新关联或归档，不按 URL 自动合并。

### 后台服务生命周期

一键脚本和 `npm start` 启动独立后台进程；启动程序退出后服务继续运行，重复启动复用现有服务。`npm stop` 和 `npm restart` 核对启动身份，停止等待已接受写入完成。相关进程与 HTTP 测试使用独立临时目录、临时端口和虚构来源。

回归覆盖停止与重启后配对及配置保留、陈旧启动身份拒绝停止、旧版前台服务提示、停止鉴权、写入排空、离线启动指引、迟到同步不覆盖已停止状态，以及状态与停止入口。配对码仅显示在启动窗口和私有运行信息中，配对成功后从运行信息移除，不写入后台日志。

### 首次接入与诊断

接入流程为启动本机服务 → 配对 → 发现来源 → 预览 → 启用。非敏感配置草稿可保存并恢复，恢复时重新预览；改动目录、读取方式或时间范围会使预览失效。配对码、预览正文及连接器声明的敏感字段不进入草稿。

发现依据来自当前用户环境、连接器规则和实际目录元数据，发现阶段不读取会话或名称文件正文。同一真实目录和别名路径去重；名称资料必须有实际文件依据。预览按最后活动时间处理近 3 / 7 / 30 天，按稳定身份统计主会话与子会话，最多显示 10 条主会话优先的样例；样例截断与读取不完整分别提示。SDK 标记不是特定客户端的唯一身份证明。

回归覆盖目录缺失、读取权限错误、格式不支持、无近期会话、预览不持久化正文或游标、全量计数与样例区分、共享目录、配对码错误/过期/已用、来源鉴权、草稿恢复、迟到结果、初次同步失败保留已保存配置。空兼容目录可启用；不支持格式不能绕过预览或编辑校验。

启动窗口展示服务地址、配对码、实际截止时间和剩余时间。重复启动不重置原码有效期；重启可获取新码，已有配对保留。原生目录选择器使用固定 AppleScript，无用户内容插入；最多一个窗口、两分钟超时、取消正常返回。脚本已静态编译，进程成功、取消、权限、超时和并发分支经过模拟测试；原生窗口实点仍待验证。

## 2. 真实历史读取边界

Codex rollout 与 Claude 格式 JSONL 两种连接器均完成过真实历史读取验证，包括稳定身份、父子关系、独立名称资料、近期活动筛选和旧命名缓存修复。本节结论来自真实来源读取，不能视为虚构数据测试。

缺少原始创建时间时保持未知，不用文件时间或扫描时间补齐；无法可靠确认的名称与首条消息也保持缺失。历史消息不能证明实时运行状态或任务已完成。超长行可能跳过部分内容，大文件可能分批读取，因此不宣称完整历史无损导入；真实模型生成名称的质量仍未验收。
