# Task Out

在 Chrome 新标签页里，按项目集中查看网页与兼容 Agent 会话。项目不绑定工作目录，每条记录至多选择一个主要类型；每条会话保留独立上下文。

Task Out 基于 [Zara Zhang 的 Tab Out](https://github.com/zarazhangrui/tab-out) 迭代。当前仓库提供真实扩展与本机连接服务，已完成部分 Chrome 实机流程及两种格式的真实会话读取，仍处于首版开发验收阶段；完整 Chrome 操作和干净环境安装尚待验收。实际结果见[验证记录](docs/validation.md)。

## 使用方式

| 组件 | 负责什么 |
|---|---|
| Chrome 扩展 | 网页、项目与标签、书签、归档、会话详情、直接请求模型 |
| 可选本机服务 | 发现和读取已启用的本地会话目录，保存连接配置与必要缓存 |
| 标准导入 | 没有连接器的工具可先导出标准 JSON / JSONL，再导入查看 |

仅使用网页功能不需要运行本机服务，也不要求配置模型。普通网页预览不具备扩展的页签管理和本机连接能力。

## 安装与首次接入

1. 下载或克隆本仓库：`git clone https://github.com/yuuuyua-ux/task-out.git`。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择仓库内的 `extension/` 目录。
4. 新开一个标签页即可使用 Task Out。代码更新后，在扩展管理页点击重新加载。

无需构建，也无需安装 npm 依赖。本机服务需要 **Node.js 24（≥24.12.0，<25）**，当前验证版本为 24.12.x，可从 [Node.js 官网](https://nodejs.org/) 安装。

接入本地会话时，在「设置 → 会话来源」进入「接入本机会话」，按五步引导完成：

1. **启动**：macOS 双击 [`scripts/Start Task Out.command`](scripts/Start%20Task%20Out.command)，或在仓库目录运行 `npm start`。启动窗口显示服务地址、配对码与有效期；回到页面点击「已启动，检查连接」。
2. **配对**：复制启动窗口的配对码，并允许 Chrome 访问该本机地址。默认地址是 `http://127.0.0.1:4518`，自定义地址收在高级设置中。配对码 10 分钟内有效、成功后一次失效；保存的连接凭据跨服务重启保留。
3. **发现**：自动检查当前用户的兼容会话目录和可用名称资料位置，按普通名称和图标展示候选。此时不读会话正文；找不到时可手动选择目录。同一实际目录只显示一份候选，不把 SDK 入口固定认成某个客户端。
4. **预览**：确认页面明确列出的会话目录、可选名称资料目录和近 **3 / 7 / 30 天**范围，再点击「读取并预览」。目录、格式及身份修正收在高级设置中。预览展示主会话数量、子会话数量和最多 10 条样例，不把样例数当总数；点击预览才授权读取所选范围，不调用模型。
5. **启用**：预览通过后「确认并启用」。当前窗口无会话时仍可启用等待新活动；格式不支持或没有读取权限时先修复。默认获取近 30 天，新连接每 60 秒增量读取；首页仍默认近 3 天会话加全部浏览器页签。

引导可关闭后继续，已保存配对和配置草稿会保留，配对码不存入草稿；返回后重新预览再启用。保存成功但首次同步失败时保留连接，在完成页重试同步，无需重复添加。服务未启动、Chrome 未授权、配对码错误/过期/已使用、目录不存在、读取无权限和格式不兼容分别提供处理提示。

在「设置 → 会话与进展刷新频率」可选择每 30 / 60 / 120 / 300 秒，或仅手动刷新；默认每分钟。

启动成功后可以关闭终端窗口，服务会在后台继续运行。一键脚本在交互终端中保留连接信息，复制后按回车关闭；重复启动复用同一服务。配对码过期或已使用时，双击 [`scripts/Restart Task Out.command`](scripts/Restart%20Task%20Out.command) 获取新码，原有配对保留。在扩展「设置 → 管理会话来源」可查看运行状态、刷新状态和停止服务；停止后记录、来源配置与配对保留。也可运行 `npm stop` 停止、`npm restart` 重启。电脑重启后需再次双击脚本，不设置开机自启。旧版前台服务升级时，先在原终端按 `Ctrl+C` 停止，再运行更新后的脚本；扩展也需重新加载一次。路径和端口可配置，详见[连接器与本机服务说明](docs/connectors.md)。

## 当前能力

- 首页默认展示近 3 天有更新的对话和全部已打开网页；在「筛选」中可调整时间、来源、项目与排序。时间始终按最近活动判断：旧会话近期有更新也会显示，切换创建时间排序不会改变筛选口径；网页不受时间筛选影响。首页操作区只保留「设置」，模型、来源、新建项目、重新整理、撤销和数据管理集中在其中。
- 多列项目卡片、来源图标、搜索与类型筛选、最近发起、会话近况和最近活动。每次更新重建可见分组，空组和无内容的分组筛选项自动消失。真正无记录引用的项目自动清理，无需确认；归档或超出时间窗的记录仍保留项目定义，撤销移动可恢复原分组。
- 按项目查看时，“未归类”单独放在卡片上方的浅色虚线区域，标明“尚未加入项目”，可收起。支持拖入项目、打开、查看详情和归档；筛选、排序及总数仍涵盖两区，未归类为空时自动隐藏。按来源查看时继续按来源聚合所有记录。
- 在「设置 → 会话来源 → 图标与颜色」调整已出现来源的外观，浏览器和会话均支持。可选择内置图标、8 种预设颜色或自选颜色，也可恢复默认；同一来源在首页和详情保持一致。设置保存在扩展本地，来源同步和重启不会覆盖，无需启动本机服务。
- 卡片采用自适应瀑布流，后续卡片接在较短的列下方；宽度、字体或内容改变时自动重排，窄屏为单列。默认按最近活动排序：卡片取当前可见成员的最新活动，卡片内也从新到旧；网页活动是最近访问/激活，会话活动是来源日志最近事件。
- 类型固定为 **调研分析、需求规划、方案设计、开发实现、测试排障、文档整理、使用咨询**。每条记录至多一个主要类型，也可未设置；手动编辑与模型整理使用同一组选项。类型栏只列当前范围内正在使用的类型，选中类型失效时回到「全部」。旧标签有明确映射时自动收敛；工具名、主题名等不再作为类型筛选，原标签备份到 `user.legacyTypeTags`。
- 网页点击直达具体页签；同网址的多个真实页签保持独立。浏览器重启等情况下不能可靠关联的旧记录保留在「设置」→「数据管理」→「历史网页」，已有分类仍保留，当前总览不重复展示这些旧记录。此处数量按未关联当前标签页的旧记录统计，与是否已分类独立。
- 书签只标记「稍后查看」。× 统一归档：网页先保存再关闭选中的页签，会话仅在 Task Out 中归档；恢复不会重新启动 Agent。归档成功后播放短声效、收起动画和纸屑反馈，失败项不播放；开启系统「减少动态效果」时只保留声效。
- 项目、标签、归档、书签与人工修正持久化到扩展 IndexedDB；来源同步不会覆盖用户整理结果。
- 连接器目前包含 **Codex rollout** 与 **Claude 格式 JSONL**，支持历史与增量读取、可配置目录、暂停、编辑、移除及断连缓存。
- 会话按来源记录的最近活动时间进入滚动的 3 / 7 / 30 天窗口。收窄范围或记录自然过期后，从当前内容和稍后查看中隐藏；本地项目、名称、标签等整理结果保留，扩大范围后可重新显示。归档记录继续保留。
- 默认由 AI 自动整理并应用：新会话归类一次，可在授权范围内补全缺失名称和近况；已有会话只更新近况，不自动改变项目、主要类型或固定名称。网页继续按原标题和地址整理。人工调整保持优先，操作可撤销；设置内可「刷新进展」、主动「重新整理当前内容」或处理已有的待确认建议。

Chrome 工具栏和新标签页使用 Task Out 独立的靛紫清单图标，与原 Tab Out 图案区分。

两个连接器目前均不提供经验证的实时运行状态或原会话直达入口，状态显示「未知」。Claude `sdk-ts` 仅说明 SDK 入口，不能唯一证明来自 Mana；来源不明确时使用通用标识，可手动纠正。创建时间缺失时不以文件时间或首次扫描时间代替。

获取范围用于本地会话连接，不会筛除仍打开的浏览器页签。最近活动时间未知或在未来的会话不进入该窗口，不以文件复制或修改时间补齐。旧版「全部历史」配置升级为近 30 天；已有整理和归档不会被删除。

## 会话名称

优先显示原应用的会话名称。Codex 可在来源连接中选择「名称资料目录」，读取当前存储的会话名称索引或兼容状态数据库；发现候选不会自动读取。Claude 格式优先读取 `custom-title`。具体优先级及范围见[连接器说明](docs/connectors.md)。

没有原名时先用首条有效用户消息临时显示。推荐插件、环境说明、委派包装和恢复上下文等系统信息会被排除，不作为命名依据；已有缓存按新规则修复。单独允许首条和最新消息参与命名后，新会话首次自动整理可一并补全名称。已归类会话不会借后续进展刷新重新命名；仍缺名称时，可从详情生成名称，或主动重新整理。应用后名称固定，后续消息、同步、来源名补齐都不改写它，仍可手动修改或撤销。手动别名始终优先；未在 Task Out 固定名称的记录会跟随来源明确的改名。

## 模型与数据范围

在「设置」→「配置模型与自动整理」填写「模型服务地址（兼容 OpenAI 格式）」、模型名称、API Key 和分组偏好。支持 HTTPS 网关和本机 HTTP 服务，本地无认证模型允许不填 Key。保存地址时 Chrome 会请求相应站点的访问权限。

**模型请求由扩展独立发起，本机服务不接收模型 Key，也不代理模型请求。** Key 只保存在扩展 `chrome.storage.local`，访问范围限制为 `TRUSTED_CONTEXTS`；不进入导出、日志或公开配置。已有配置时，地址、模型名称、Key 和分组偏好留空均保持原值；仅修改填写的字段。Key 只有明确点击「清除 Key」并保存才删除。更换服务地址时，若已有 Key，需填写新 Key 或明确清除后再保存，未处理前保留原配置，旧 Key 不会自动交给新地址。

- 自动整理默认开启，配置可用后处理已打开网页和近 3 天有活动的已授权主会话；默认不开启任何会话来源的外发权限。新会话只自动归类一次，已归类会话的新活动进入进展更新，不重新分组或命名。可以在模型设置关闭，关闭选择跨重启保留。旧版仅有“自动建议”设置的配置采用新的默认自动整理规则。
- 会话与进展刷新默认 60 秒，可改为 30 / 120 / 300 秒或仅手动刷新（0）。频率保存后跨重启保留；仅手动刷新会话不关闭网页自动整理，也不停止本机服务的独立目录读取。没有获准输入变化不请求模型；网页激活、同步时间和模型自己写回的结果不算新内容。已处理的空结果和撤销不会马上重新触发。
- 「刷新进展」只更新有变化且获准发送的会话近况；「重新整理当前内容」可主动重新归类当前筛选内容，仍不覆盖人工字段或固定名称。模型或分组偏好变化不会自动重分组老会话。错误显示在整理状态中，支持重试；真实外部模型效果仍待验证。
- 首页失败状态直接显示简短原因，如「自动整理失败：模型响应超时」。点击「查看原因」可看处理建议和折叠的详细错误；未知错误不推测原因，自动整理关闭时手动失败显示「整理失败」。
- 分组请求使用短编号，减少模型抄错项目标识；把已有项目名称填入编号时，仅在名称完全匹配且唯一时识别。无法识别的引用自动纠正一次，仍失败则保留已有整理，不猜测归属或把错误编号创建为项目。
- 网页按浏览器实际标题和地址分类；手动显示别名不会替换分类使用的原标题。保留搜索参数、文档定位和页面路由，移除 URL 认证信息及可识别的 token、密码、Key 等凭据参数；不读取网页正文或浏览历史。
- 本地会话默认禁止参与 AI 整理。需要使用时，在连接配置中明确允许标题，按需另行允许一句近况或用于命名的首条和最新消息节选（各最多 1200 字符）；多连接指向同一记录时采用更严格的限制。没有原名时，临时展示的首条消息不会作为标题绕过消息授权。
- 不发送完整会话历史、附件或单独的本地文件定位字段；允许发送的消息节选可能包含其正文中的路径等信息。「保存并测试整理」使用两条虚构网页和一个示例项目，执行与正式整理相同的分类及结果校验；不使用真实会话或个人分组偏好。通过表示连接和示例分类可用，不代表所有真实内容都能正确分类。

## 用量与费用

在「设置 → 用量与费用」查看今天、近 7 天、近 30 天的调用次数、输入/输出/缓存 token、每日趋势、按模型统计与最近 100 次调用。只统计 **Task Out 自己**发起的分组、进展、命名和测试调用，不包含 Codex、Claude 等原应用用量；测试单独标注，重试按实际请求逐次计入，失败或取消的已发出请求也保留记录。升级前没有统计的历史不会补造。

在同一页面按模型服务地址和模型名称设置每百万 token 的输入、输出与缓存输入单价，可选 CNY / USD / EUR。留空保留已有单价，首次留空表示未知，明确填 0 才表示免费。修改只用于后续调用；每次请求开始时保存当时单价，历史估算不重算。不同币种分别显示，不做汇率换算。

接口没有返回完整用量或尚未配置必要单价时，未知部分不会计成 0；缓存用量或缓存价缺失时按普通输入价估算，并标明未计缓存优惠。累计记录至少 24 小时后，按近期最多 7 天的日均使用估算未来 30 天；数据不完整时标记部分估算。这里是本地估算，实际费用以供应商账单为准。账本不保存请求正文或模型 Key。

## 导入、导出与升级

「设置」中的「导入」接受每个对象代表一条记录的 JSON / JSONL，不接受任意工具的原始事件日志。先填写稳定的数据集标识并预览，重复导入同一数据集和 `id` 会更新同一条记录。可试用[虚构样例](examples/records.example.jsonl)，字段说明见[连接器文档](docs/connectors.md#标准导入)。

「导出」区分两种用途：

- **内容备份**：个人记录、整理结果和来源外观，可能含标题、网址、近况和本地定位信息，应当作为私人文件保存。导入后不恢复真实页签绑定，也不恢复凭据；已有的来源外观自定义优先保留。
- **配置模板**：供分享的空配置，去除机器路径、私有地址和密钥。它不是完整环境备份；在新环境中依据模板填写连接表单并重新配对、测试。可参考[配置样例](examples/connections.example.json)。

以相同扩展 ID 升级时，Task Out 提供旧主题、稍后查看和完成标记的迁移预览，并保留原始备份。安装成另一个扩展 ID 时，Chrome 不允许直接读取旧扩展的存储，不能自动迁移；请保留旧安装并通过导出/标准导入迁移可用数据。

## 开发与验证

```sh
npm run check
npm test
npm start
```

语法与入口检查无需构建。自动测试覆盖页签实例操作、归档恢复、持久化与迁移、来源读取和鉴权、模型发送范围与建议冲突等。服务测试会临时监听回环随机端口，仅使用虚构记录并自动清理。

自动测试不代替 Chrome 实机验收。[验证记录](docs/validation.md) 分别列出自动回归、真实会话读取、浏览器已完成步骤和待验收项。更多产品规则见[产品方案](docs/product-plan.md)，连接器扩展入口见[开发说明](docs/connectors.md)。
